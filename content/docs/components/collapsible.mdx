## Overview

Use a collapsible when one piece of content can be shown or hidden by a single control.

Collapsible is simpler than accordion. It is a good fit for optional details, advanced settings, helper text, or a single expandable section.

## Anatomy

A collapsible has a root, trigger, and content. The trigger controls whether the content is visible. The content should be directly related to the trigger.

## Behavior

Use collapsible when there is only one expandable region. If you have several related expandable regions, use Accordion instead.

## Accessibility

The trigger should be a real button with clear text. Keep focus visible and make sure the expanded state is communicated by the primitive.

## Usage

```tsx
import {
  Collapsible,
  CollapsiblePanel,
  CollapsibleTrigger,
} from "@/components/ui/collapsible";
```

```tsx
<Collapsible>
  <CollapsibleTrigger>Show command options</CollapsibleTrigger>
  <CollapsiblePanel>
    Add `--dry-run` to preview changes without writing files.
  </CollapsiblePanel>
</Collapsible>
```

## API reference

`Collapsible`, `CollapsibleTrigger`, and `CollapsiblePanel` forward their matching Base UI Collapsible props. `CollapsibleContent` is an alias of the panel. Use `open` and `onOpenChange` for controlled state or `defaultOpen` for uncontrolled state.

The trigger owns disclosure behavior and keyboard handling; do not add a second click handler to the panel. See the [Base UI Collapsible API](https://base-ui.com/react/components/collapsible#api-reference).
