## Overview

Use Preview Card to show a small preview when a user hovers or focuses a link.

Preview cards are useful for profiles, documents, issues, pages, and references where a quick summary helps users decide whether to open the link.

## Anatomy

A preview card has a trigger link and popup content. The popup usually includes a title, short description, metadata, and sometimes media.

## Usage guidance

Keep preview content brief. It should help users understand the destination, not replace the destination page.

## Accessibility

The link must still work without the preview. Do not put essential actions only inside hover-only content.

## Decision guidance

Use Preview Card for optional supporting context that appears after intentional hover or keyboard focus. The trigger should still work without the preview, and important facts or actions must remain available on the destination page. Use Popover when people must interact with the floating content.

## API reference

Preview Card parts forward their matching Base UI Preview Card props. The `HoverCard` names are aliases for compatibility. Use the viewport when coordinating popup size and the arrow only when it helps connect the popup to its trigger.

See the [Base UI Preview Card API](https://base-ui.com/react/components/preview-card#api-reference).
