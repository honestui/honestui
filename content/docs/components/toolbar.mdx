## Overview

Use Toolbar to group controls that act on the same surface.

Toolbars are useful in editors, tables, canvases, filters, and dashboards where several commands belong together.

## Anatomy

A toolbar can contain buttons, links, inputs, toggles, groups, separators, menus, and other compact controls. `ToolbarButton`, `ToolbarLink`, and `ToolbarInput` participate in the toolbar's roving keyboard navigation.

## Usage guidance

Keep the most common actions visible and group related commands. Move less common actions into a menu when the toolbar becomes crowded. Use a horizontal toolbar by default; vertical orientation is appropriate only when the controlled surface and labels make the direction obvious.

## Accessibility

Give the toolbar an accessible label when the surrounding heading does not name it. Icon-only controls need accessible names, toggles need a persistent pressed state, and separators must not receive focus. Arrow keys move among toolbar controls; Tab should move into and out of the toolbar as one stop.

## Usage

```tsx
import { Button } from "@/components/ui/button";
import { Toggle } from "@/components/ui/toggle";
import {
  Toolbar,
  ToolbarButton,
  ToolbarGroup,
  ToolbarInput,
  ToolbarLink,
  ToolbarSeparator,
} from "@/components/ui/toolbar";
```

```tsx
<Toolbar>
  <ToolbarGroup>
    <ToolbarButton render={<Toggle />}>Bold</ToolbarButton>
    <ToolbarButton render={<Toggle />}>Underline</ToolbarButton>
  </ToolbarGroup>
  <ToolbarSeparator />
  <ToolbarButton render={<Button />}>Save document</ToolbarButton>
</Toolbar>
```

## API reference

All Toolbar parts forward their matching Base UI Toolbar props. Use `orientation="vertical"` on `Toolbar` when needed. `ToolbarGroup` creates a related subset; `ToolbarSeparator` follows the root orientation; and the Button, Link, and Input parts provide the focusable controls.

See the [Base UI Toolbar API](https://base-ui.com/react/components/toolbar#api-reference) for keyboard behavior and root props.
