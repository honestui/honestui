## Overview

Use Progress to show how far a task has advanced.

Progress is useful for uploads, imports, onboarding steps, generation, installation, and long-running actions. Use Meter for static values like quota or capacity.

## Anatomy

A progress indicator has a value, maximum, optional label, optional formatted value, and visual bar.

## Behavior

Use determinate progress when you know the percentage. Pass `value={null}` for indeterminate work, and replace it with a number as soon as the application can estimate progress. Do not show a made-up percentage simply to make an operation feel active.

## Accessibility

Name the operation with `ProgressLabel` or `aria-label`. Show text when the value matters. Do not communicate progress only through animation or color, and keep completion feedback visible after the indicator disappears. Honest UI limits indeterminate animation when reduced motion is requested.

## Usage

```tsx
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@/components/ui/progress";
```

```tsx
<Progress value={40} />
```

Note: If you render children inside `Progress`, you must also include `ProgressTrack` and `ProgressIndicator` inside it. Without them, the bar will not display. When no children are provided, a default track and indicator are rendered for you.

## API reference

`Progress` accepts Base UI Progress root props plus `variant="linear" | "circular"`. Its defaults are `min={0}` and `max={100}`; pass `null` as the value for indeterminate progress. When it has no children, it renders the matching track automatically. The label, track, indicator, and value parts forward Base UI props; `ProgressCircularTrack` accepts native SVG props.

See the [Base UI Progress API](https://base-ui.com/react/components/progress#api-reference) for value formatting and state details.
