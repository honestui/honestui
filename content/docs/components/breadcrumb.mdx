## Overview

Use breadcrumbs to show where the current page sits in a hierarchy.

Breadcrumbs work best for nested products, documentation, settings, folders, and admin sections. They should not replace the main navigation. They help users understand context and move up one or more levels.

## Anatomy

A breadcrumb has a list, items, links, separators, and a current page item. Earlier items are usually links. The current item is plain text with `aria-current="page"`. `BreadcrumbIcon` aligns an icon with a label, while dropdown parts let a Menu hold levels that do not fit.

## Usage guidance

Keep labels short and preserve the real hierarchy. Start with the highest useful parent, not automatically the site root. On narrow screens, collapse middle levels into a menu instead of truncating the current page. Use custom separators only when they still read clearly between items.

## Accessibility

`Breadcrumb` renders a navigation landmark labeled “breadcrumb.” Mark the current page so assistive technology can distinguish it from links. Give an icon-only dropdown trigger an accessible name, keep separators hidden from assistive technology, and make every hidden level available by keyboard.

## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb";
```

```tsx
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbEllipsis />
    </BreadcrumbItem>
    <BreadcrumbItem>
      <BreadcrumbLink href="/components">Components</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## API reference

`Breadcrumb` accepts native `nav` props and a `size` of `small` or `medium`. The list, item, page, separator, ellipsis, and icon parts accept their matching native element props. `BreadcrumbLink`, `BreadcrumbDropdownTrigger`, and `BreadcrumbDropdownItem` also accept Base UI `render` props so they can compose with your router and menu components.
