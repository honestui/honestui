## Overview

Use Separator to divide related content or controls.

Separators are useful in menus, toolbars, cards, settings pages, and layouts where a visual break makes scanning easier.

## Anatomy

A separator is a horizontal or vertical line. It can be decorative or semantic depending on how it is used.

## Usage guidance

Use separators sparingly. Spacing and headings should do most of the grouping work. Add a separator when the visual boundary improves clarity.

## Accessibility

If the separator communicates structure, keep it accessible. If it is only decorative, hide it from assistive technology.

## Decision guidance

Separator marks a visual boundary between related regions. It should reinforce spacing and headings, not repair an unclear hierarchy. Use a border when the boundary belongs to a container edge, and use whitespace alone when the relationship is already obvious.

## API reference

`Separator` forwards Base UI Separator props. Set `orientation="horizontal"` or `"vertical"` to match the visible line. Decorative separators remain outside the accessibility tree; use a heading or landmark when the division needs a semantic name.

See the [Base UI Separator API](https://base-ui.com/react/components/separator#api-reference).
