## Overview

Use Menu for a compact list of actions or choices opened from a trigger.

Menus are useful for overflow actions, account menus, row actions, editor commands, and grouped command lists. Do not use a menu for primary navigation when links should stay visible.

## Anatomy

A menu has a trigger, popup, items, optional groups, labels, separators, checkbox items, radio items, links, and nested submenus.

## Behavior

Keep menu labels short and action-oriented. Use nested menus sparingly because they require more pointer and keyboard precision.

`MenuPopup` limits itself to Base UI's available viewport height and scrolls vertically when its content is taller. To give a long menu a smaller product-specific limit, pass a `max-height` class that keeps `--available-height` as the upper bound, such as `max-h-[min(18rem,var(--available-height))]`.

## Accessibility

Menu items should be reachable with arrow-key navigation, including items outside the initially visible scroll area. Wheel and touch scrolling should not move the page once the menu reaches its edge. Use checkbox and radio menu items only when the checked state matters inside the menu.

If a list becomes difficult to scan even with scrolling, use Autocomplete or Combobox instead. Search and filtering are more useful than forcing people through a very long action menu.

## Usage

```tsx
import {
  Menu,
  MenuCheckboxItem,
  MenuGroup,
  MenuGroupLabel,
  MenuItem,
  MenuPopup,
  MenuRadioGroup,
  MenuRadioItem,
  MenuSeparator,
  MenuSub,
  MenuSubPopup,
  MenuSubTrigger,
  MenuTrigger,
} from "@/components/ui/menu";
```

```tsx
<Menu>
  <MenuTrigger>Open</MenuTrigger>
  <MenuPopup align="start" sideOffset={4}>
    <MenuItem>Profile</MenuItem>
    <MenuSeparator />

    <MenuGroup>
      <MenuGroupLabel>Playback</MenuGroupLabel>
      <MenuItem>Play</MenuItem>
      <MenuItem>Pause</MenuItem>
    </MenuGroup>

    <MenuSeparator />

    <MenuCheckboxItem>Shuffle</MenuCheckboxItem>
    <MenuCheckboxItem>Repeat</MenuCheckboxItem>

    <MenuSeparator />

    <MenuGroup>
      <MenuGroupLabel>Sort by</MenuGroupLabel>
      <MenuRadioGroup>
        <MenuRadioItem>Artist</MenuRadioItem>
        <MenuRadioItem>Album</MenuRadioItem>
        <MenuRadioItem>Title</MenuRadioItem>
      </MenuRadioGroup>
    </MenuGroup>

    <MenuSeparator />

    <MenuSub>
      <MenuSubTrigger>Add to playlist</MenuSubTrigger>
      <MenuSubPopup>
        <MenuItem>Jazz</MenuItem>
        <MenuItem>Rock</MenuItem>
      </MenuSubPopup>
    </MenuSub>
  </MenuPopup>
</Menu>
```

## API reference

Menu exports root, trigger, portal, backdrop, popup, arrow, item, group, group label, separator, checkbox item, radio group, radio item, and submenu parts. Each forwards its matching Base UI Menu props; link composition uses the `render` prop on an item.

Use the root's controlled props only when another part of the application must own open state. See the [Base UI Menu API](https://base-ui.com/react/components/menu#api-reference) for focus, submenu, checkbox, and radio behavior.
