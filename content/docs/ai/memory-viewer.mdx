## Overview

Memory Viewer shows what an agent has learned and keeps: facts about the person, their preferences, and the projects they work on. Each memory shows where it came from, when it was learned, when it was last used, and how sure the agent is. People can search, correct a memory, pin the ones that matter, and forget the rest.

It shows the memories you pass and calls back on every change. Storing them, and giving them to the agent, is your application's work.

## Behavior

### Groups

Memories are grouped by `kind`. The default groups are About you, Preferences, Facts, and Projects. Pass `groups` to rename or reorder them; memories of other kinds are listed after them. Pinned memories lead their group.

### Search and filter

Search matches the memory and its source, and marks the match. The filter shows one group at a time, with a count for each. Both can be controlled with `query` and `filter`.

### Editing

Edit turns the memory into a field. <kbd>Enter</kbd> or Save keeps the change, <kbd>Shift</kbd>+<kbd>Enter</kbd> adds a line, and <kbd>Escape</kbd> or Cancel leaves it as it was. Saving unchanged or empty text calls nothing.

### Forgetting

Forget appears when you pass `onForget`, along with a checkbox on each memory for forgetting several at once. What happens next depends on `onRestore`:

- **With `onRestore`**, forgetting happens at once and an Undo bar stays for eight seconds. Undo calls `onRestore` with the forgotten memories.
- **Without it**, Forget asks to confirm first, inline, because it cannot be taken back.

### Dates and confidence

Learned dates are absolute and last-used dates are relative, measured from `now` or the reader's clock after the page loads. Confidence below `lowConfidence` (0.5 by default) is marked Unsure.

## Accessibility

The viewer is a region named by its title, and each group is a list named by its label. Every action is named with its memory, such as "Forget: Works from Lisbon". The filter buttons report whether they are pressed. Focus returns to Edit after editing and moves to Undo after forgetting, and the Undo bar is announced.

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Move across search, the filters, the checkboxes, and the actions |
| <kbd>Enter</kbd> or <kbd>Space</kbd> | Press the focused control |
| <kbd>Escape</kbd> | Cancel an edit or a confirmation |

## Usage

```tsx
import { MemoryViewer } from "@/components/ai/memory-viewer"

<MemoryViewer
  memories={memories}
  onEdit={(id, content) => memory.update(id, { content })}
  onForget={(ids) => memory.forget(ids)}
  onRestore={(items) => memory.restore(items)}
  onPinnedChange={(id, pinned) => memory.update(id, { pinned })}
/>
```

## API reference

### MemoryViewer

Accepts native section props beyond those listed.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `memories` | `MemoryItem[]` | Required | What the agent remembers. |
| `groups` | `MemoryGroup[]` | About you, Preferences, Facts, Projects | Group order and names. |
| `onEdit` | `(id: string, content: string) => void` | None | Passing it shows Edit. |
| `onForget` | `(ids: string[]) => void` | None | Passing it shows Forget and selection. |
| `onRestore` | `(memories: MemoryItem[]) => void` | None | Passing it makes forgetting immediate, with Undo. |
| `onPinnedChange` | `(id: string, pinned: boolean) => void` | None | Passing it shows Pin. |
| `query` | `string` | None | Controls the search text. |
| `defaultQuery` | `string` | `""` | The starting search text. |
| `onQueryChange` | `(query: string) => void` | None | Called as the search changes. |
| `filter` | `string \| null` | None | Controls the group shown; `null` shows all. |
| `defaultFilter` | `string \| null` | `null` | The starting group. |
| `onFilterChange` | `(kind: string \| null) => void` | None | Called when a filter is pressed. |
| `lowConfidence` | `number` | `0.5` | Confidence below this is marked Unsure. |
| `now` | `Date` | The reader's clock | The time relative dates are measured from. |
| `locale` | `string` | The reader's | Formats dates. |
| `labels` | `Partial<MemoryViewerLabels>` | English | Every visible and announced string. |

### Types

| Export | Shape |
| --- | --- |
| `MemoryItem` | `id`, `content`, `kind`, `createdAt`, and optional `source`, `lastUsedAt`, `confidence`, and `pinned` |
| `MemoryGroup` | `kind` and `label` |
