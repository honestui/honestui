## Overview

Chat Welcome is what a new conversation opens on: a greeting, a line on what the assistant can help with, and a few [Prompt Suggestions](/docs/ai/prompt-suggestions) to start from.

Give it a `composer` for a full-page start, or drop it into [Chat Thread](/docs/ai/chat-thread)'s `emptyMessage`, where it gives way to the first message.

## Behavior

### Suggestions

Pass `suggestions` and `onSelectSuggestion` to show starters. A common choice is to put the prompt in the composer, so the person can change it before sending. `suggestionsLayout` takes the same layouts as Prompt Suggestions.

### Alignment

`center` suits a new chat page. `start` aligns everything to the left, for a narrow side panel.

## Accessibility

The welcome is a region named by its title, which is a level-two heading. The icon is decorative. The suggestions behave as in [Prompt Suggestions](/docs/ai/prompt-suggestions#accessibility).

## Usage

```tsx
import { ChatWelcome } from "@/components/ai/chat-welcome"
import { PromptBar } from "@/components/ai/prompt-bar"

<ChatWelcome
  title="What should we look into?"
  description="Ask about invoices, payouts, or a failed export."
  composer={<PromptBar value={draft} onValueChange={setDraft} onSubmit={send} />}
  suggestions={starters}
  onSelectSuggestion={(suggestion) => setDraft(suggestion.prompt)}
/>
```

## API reference

### ChatWelcome

Accepts native section props beyond those listed.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `ReactNode` | Required | The greeting. |
| `description` | `ReactNode` | None | What the assistant can help with. |
| `icon` | `ReactNode` | None | A decorative mark above the title. |
| `suggestions` | `PromptSuggestion[]` | None | Prompt starters. |
| `onSelectSuggestion` | `(suggestion) => void` | None | Called with the chosen starter. Needed to show them. |
| `suggestionsLayout` | `"wrap" \| "scroll" \| "list"` | `"wrap"` | How the starters are laid out. |
| `composer` | `ReactNode` | None | A composer under the greeting. |
| `align` | `"center" \| "start"` | `"center"` | Centered, or aligned to the start. |
| `disabled` | `boolean` | `false` | Turns the starters off. |
| `labels` | `Partial<ChatWelcomeLabels>` | English | The starters' accessible name. |
