## Overview

In a voice conversation there is no text to read while the turn changes hands. Voice Orb gives the person something to watch: it breathes at rest, swells with their voice while it listens, turns while the assistant thinks, and ripples with the reply while it speaks.

It shows state; it does not decide it. `state` comes from your voice pipeline, and `inputLevel` and `outputLevel` are loudness figures you measure. The orb opens no microphone and plays no audio.

## Behavior

### States

| State | What it shows | Level it follows |
| --- | --- | --- |
| `idle` | A slow breath | None |
| `listening` | A swell and a rippling edge | `inputLevel` |
| `thinking` | An arc travelling around the outside | None |
| `speaking` | A livelier ripple | `outputLevel` |

The state is reported as `data-state` on the root. A change of state or a jump in level eases in, so the orb never snaps.

### Levels

A level is a number from 0 to 1. Pass a number when it comes from React state, or a function the orb calls once per frame, which avoids re-rendering on every audio frame:

```tsx
<VoiceOrb state="listening" inputLevel={() => meter.current} />
```

Values outside 0 to 1 are clamped.

### Color

The orb is drawn in the text color, so it is dark on light surfaces and light on dark ones. Pass `accent` with any CSS color to tint it; the color is read at draw time, so tokens such as `var(--hui-color-foreground-accent-primary)` follow the theme.

## Accessibility

The canvas and glyph are hidden from assistive technology. A visually hidden status reads the state, such as "Listening", and is announced when it changes. If text nearby already says the state, set `announce` to `false` so it is not read twice.

The orb is not interactive. Put your microphone and stop controls next to it as real buttons.

With reduced motion, the orb does not animate: it shows a still glyph for the state, a dot, a microphone, three dots, or bars.

Every string comes from `labels`.

## Usage

```tsx
import { VoiceOrb } from "@/components/ai/voice-orb"

<VoiceOrb
  state={session.state}
  inputLevel={() => micLevel.current}
  outputLevel={() => replyLevel.current}
/>
```

## API reference

### VoiceOrb

Accepts native div props beyond those listed.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `state` | `VoiceOrbState` | `"idle"` | What the assistant is doing. |
| `inputLevel` | `VoiceOrbLevel` | `0` | The person's loudness, followed while listening. |
| `outputLevel` | `VoiceOrbLevel` | `0` | The assistant's loudness, followed while speaking. |
| `size` | number | `96` | Diameter in CSS pixels. |
| `accent` | string | Text color | A CSS color for the orb. |
| `announce` | boolean | `true` | Reads the state in a status region. |
| `labels` | `Partial<VoiceOrbLabels>` | English | The text read for each state. |

### Types

| Export | Shape |
| --- | --- |
| `VoiceOrbState` | `"idle"`, `"listening"`, `"thinking"`, or `"speaking"` |
| `VoiceOrbLevel` | A number from 0 to 1, or a function that returns one |
| `VoiceOrbLabels` | One string per state |
