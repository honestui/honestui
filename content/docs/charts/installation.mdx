Honest UI charts are available from the `honestui/charts` package entry point. Installing `honestui` includes the chart components and their runtime dependencies.

## Install

<CommandBlock commands={["honestui"]} />

## Import

Import chart roots, shared types, and chart-specific data types from the same entry point.

```tsx
import { BarChart, type ChartConfig } from "honestui/charts";
```

## Next steps

Choose a visualization from the Components section, then use [Chart Config](/docs/charts/chart-config) to define shared labels, colors, and icons.
