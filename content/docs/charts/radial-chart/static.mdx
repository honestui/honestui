## Overview

A radial chart draws each row as a ring whose length is its value. It works best for progress toward a known maximum, such as activity goals or storage used, and for short ranked lists where a compact, round shape suits a dashboard tile. Outer rings are longer than inner rings at the same value, so use a bar chart when readers must compare values precisely, and a [Gauge Chart](/docs/charts/gauge-chart/static) for a single value with ranges.

## Anatomy

`RadialChart` owns the data, scale, ring geometry, selection, and loading state. Each row is one ring, named by `nameKey`; the first row is the outermost. `Bar` draws a series, with a muted track behind it. Add several `Bar` parts with one `stackId` to split a ring into segments. `Center` puts an HTML readout in the hole, `Label` names each ring, and `Legend` and `Tooltip` add context.

## Accessibility

The plot has an accessible name listing the series and rings; pass `ariaLabel` to describe the finding instead. Text in `Center` is real text drawn over the canvas, so it stays crisp at any zoom, but it is decorative to assistive technology, so keep the same information in the accessible name or nearby text. The tooltip and ring selection are pointer-operated.

## Usage

```tsx
import { RadialChart, type ChartConfig } from "honestui/charts";
```

```tsx
<RadialChart data={data} dataKey="visitors" nameKey="browser" config={chartConfig}>
  <RadialChart.Bar isClickable />
  <RadialChart.Center label="Visitors" />
  <RadialChart.Legend isClickable />
  <RadialChart.Tooltip />
</RadialChart>
```

With one series, each ring takes the color of its row's `config` entry, like a pie sector. With several series, colors come from each `Bar`'s `dataKey`. Set `max` when values are a share of a known total; without it the longest ring closes the circle. `startAngle` and `endAngle` follow ECharts: degrees, 0 at 3 o'clock, counterclockwise positive. A partial sweep is fitted to its own bounds, so a half circle fills the width it is given.

## API reference

<ApiHeading>RadialChart</ApiHeading>

<ApiTable>
  <ApiRow name="data" type="TData[]" required>One row per ring.</ApiRow>
  <ApiRow name="nameKey" type="keyof TData & string" required>The row field that names each ring.</ApiRow>
  <ApiRow name="config" type="ChartConfig" required>Labels and colors for rows and series. See <Link href="/docs/charts/chart-config">Chart Config</Link>.</ApiRow>
  <ApiRow name="dataKey" type="keyof TData & string">The default value field for `Bar` parts without their own.</ApiRow>
  <ApiRow name="max" type="number">The value that closes the sweep. Defaults to the largest (stacked) value.</ApiRow>
  <ApiRow name="innerRadius" type="number | string" default='"30%"'>Hole size, in pixels or a percentage of the outer radius.</ApiRow>
  <ApiRow name="outerRadius" type="number | string" default='"100%"'>Outer size, in pixels or a percentage of the fitted radius.</ApiRow>
  <ApiRow name="startAngle" type="number" default="90">Where rings start, in degrees.</ApiRow>
  <ApiRow name="endAngle" type="number" default="-270">Where a full ring ends, in degrees.</ApiRow>
  <ApiRow name="selectedKey" type="string | null">Controlled selection: a row name with one series, a series key with several.</ApiRow>
  <ApiRow name="defaultSelectedKey" type="string | null" default="null">Selection on first render.</ApiRow>
  <ApiRow name="onSelectionChange" type="(key: string | null) => void">Fires when a ring or legend entry is selected or cleared.</ApiRow>
  <ApiRow name="isLoading" type="boolean" default="false">Shows the loading skeleton.</ApiRow>
  <ApiRow name="animation" type="boolean" default="true">Plays the entrance. Reduced motion turns it off.</ApiRow>
  <ApiRow name="ariaLabel" type="string">Accessible name for the plot.</ApiRow>
  <ApiRow name="chartOptions" type="Record<string, unknown>">Escape hatch merged over the ECharts option.</ApiRow>
</ApiTable>
