## Overview

Use a combo chart when two related measures share a category axis but answer different questions: an amount drawn as bars, and a rate or trend drawn as a line. Revenue with conversion rate, rainfall with temperature, and tickets opened with tickets resolved are typical pairs.

When the two measures use different units, put the line on a right-hand axis. The right axis picks ticks that land on the left axis's grid lines, so one set of dashed lines serves both scales. Reach for a second axis only when the units really differ: two axes on the same unit invite readers to compare heights that are not comparable.

## Anatomy

`ComboChart` owns the data, the category axis, selection, the brush, and loading. `Bar` and `Line` parts add series; each one names the axis it is measured against with `yAxisId`. Add one `YAxis` per side you want labelled, and optional `Grid`, `Legend`, `Tooltip`, and `Brush` parts.

Lines always draw above bars, so a trend is never hidden behind a column. Bars and lines share one axis tooltip that lists every series at the hovered category.

## Accessibility

Two axes make a chart harder to read precisely, so name each axis with `label` or a unit in its `tickFormatter`, and give the chart a clear `ariaLabel`. The canvas exposes only that name: pair the chart with a summary or table when readers need exact values. The tooltip, legend toggles, and brush are pointer-operated; do not make them the only way to reach information.

## Usage

```tsx
import { ComboChart, type ChartConfig } from "honestui/charts";
```

```tsx
<ComboChart data={data} config={chartConfig} xDataKey="month">
  <ComboChart.Grid />
  <ComboChart.XAxis />
  <ComboChart.YAxis yAxisId="left" tickFormatter={(value) => `$${value / 1000}k`} />
  <ComboChart.YAxis yAxisId="right" tickFormatter={(value) => `${value}%`} />
  <ComboChart.Legend isClickable />
  <ComboChart.Tooltip />
  <ComboChart.Bar dataKey="revenue" isClickable />
  <ComboChart.Line dataKey="conversion" yAxisId="right" isClickable>
    <ComboChart.Dot variant="border" />
  </ComboChart.Line>
</ComboChart>
```

Give the tooltip a `valueFormatter` when the series use different units. It receives the series key, so each row can carry its own unit:

```tsx
<ComboChart.Tooltip
  valueFormatter={(value, key) => (key === "conversion" ? `${value}%` : `$${value}`)}
/>
```

## Examples

### Stacked Bars

<ComponentPreview title="stackType='stacked'" name="ex-stacked-type-echarts-combo-chart" />

`stackType="stacked"` stacks every bar series that shares an axis, so the line can show a total, a target, or an outcome against the composition. Lines are never stacked.

### Brush

<ComponentPreview title="ComboChart.Brush" name="ex-brush-echarts-combo-chart" />

Add `ComboChart.Brush` to zoom a long series. The preview strip shows the first bar series; dragging the selection filters bars and lines together.

### Reference Lines and Comparison

<ComponentPreview title="ReferenceLine and compareDataKey" name="ex-reference-lines-echarts-combo-chart" />

`ComboChart.ReferenceLine`, `ReferenceArea`, and `ReferenceDot` mark targets and periods; they are measured against the left value axis. `compareDataKey` on a `Bar` draws last period's value as a tick across the column, and on a `Line` as a faded dashed line on the same axis as the line. The tooltip adds the earlier value and the change under each compared row. See <Link href="/docs/charts/ui/reference-lines">Reference Lines</Link> and <Link href="/docs/charts/ui/comparison">Period Comparison</Link>.

### Synced Crosshair

<ComponentPreview title='syncId="share-day"' name="ex-synced-crosshair-echarts-combo-chart" />

Charts that share a `syncId` show their tooltip at the same category when any one of them is hovered, here a candlestick chart above a combo chart of trading activity. Add `ComboChart.Zoom` to zoom and pan inside the plot; it shares its window with the brush. See <Link href="/docs/charts/ui/sync">Synced Crosshair</Link> and <Link href="/docs/charts/ui/brush">Brush and Zoom</Link>.

### Loading State

<ComponentPreview title="isLoading='true'" name="ex-loading-state-echarts-combo-chart" />

`isLoading` keeps the layout with a neutral bar and line silhouette and the same loading label as the other Honest UI charts.

## API Reference

<ApiHeading>ComboChart</ApiHeading>

<ApiTable>
  <ApiRow name="data" type="TData[]" required>
    One row per category.
  </ApiRow>
  <ApiRow name="config" type="ChartConfig" required>
    Labels and theme colors for every bar and line key. See <Link href="/docs/charts/chart-config">Chart Config</Link>.
  </ApiRow>
  <ApiRow name="xDataKey" type="keyof TData & string">
    The category field. Falls back to the `XAxis` `dataKey`, then the first field that is not a series.
  </ApiRow>
  <ApiRow name="stackType" type='"default" | "stacked"' default='"default"'>
    Places bars side by side or stacks the bars on each axis.
  </ApiRow>
  <ApiRow name="barRadius" type="number" default="2">
    Corner radius for bars. A stacked column rounds only its top segment.
  </ApiRow>
  <ApiRow name="curveType" type='"linear" | "smooth" | "step"' default='"smooth"'>
    Default curve for every line.
  </ApiRow>
  <ApiRow name="barGap" type="number">
    Gap between grouped bars, in pixels.
  </ApiRow>
  <ApiRow name="barCategoryGap" type="number">
    Gap between categories, in pixels.
  </ApiRow>
  <ApiRow name="animation" type="boolean" default="true">
    Plays the intro animation. Reduced-motion preferences turn it off.
  </ApiRow>
  <ApiRow name="defaultSelectedDataKey" type="string | null" default="null">
    The series selected on first render.
  </ApiRow>
  <ApiRow name="onSelectionChange" type="(key: string | null) => void">
    Fires when a clickable bar, line, or legend item is selected or cleared.
  </ApiRow>
  <ApiRow name="isLoading" type="boolean" default="false">
    Shows the loading silhouette and label.
  </ApiRow>
  <ApiRow name="syncId" type="string">
    Charts with the same id move their crosshair and tooltip together.
  </ApiRow>
  <ApiRow name="ariaLabel" type="string">
    Accessible name for the canvas. A description of the series is generated when omitted.
  </ApiRow>
  <ApiRow name="chartOptions" type="Record<string, unknown>">
    Escape hatch merged over the generated ECharts option.
  </ApiRow>
</ApiTable>
