## Overview

A bullet chart, designed by Stephen Few, packs a gauge's information into a single row: the measure is a bar, the target is a tick across it, and shaded bands behind it mark qualitative ranges such as poor, satisfactory, and good. Stack several rows to review many metrics in the space of one gauge.

Each row has its own scale, so revenue in thousands, profit in percent, and satisfaction out of five can sit side by side. Do not compare bar lengths between rows; compare each bar with its own target and bands.

## Anatomy

`BulletChart` turns each data row into a bullet with a title, an optional description line, and a scale running from zero to the row's maximum. The maximum is the last range threshold, the value, or the target, whichever is largest, unless `maxDataKey` sets it. Compose the parts you need: `Ranges` draws the bands, `Measure` the bar, `Target` the tick, and `Axis` the per-row tick labels. Add `Tooltip` and `Legend` for detail.

The bands run from darkest to lightest using shades of the foreground color, as Few recommends, so they stay readable in grayscale and never compete with the measure's color.

## Accessibility

The default `ariaLabel` reads every row's value and target, so a screen reader hears the whole comparison without the canvas. Name ranges with `rangeLabels` so the tooltip can say which band a value falls in. If being over or under target matters, say it in nearby text too: the tick's position alone is a subtle cue.

## Usage

```tsx
import { BulletChart, type ChartConfig } from "honestui/charts";
```

```tsx
const data = [
  { metric: "Revenue", unit: "USD, thousands", actual: 271, target: 250, ranges: [150, 225, 300] },
  { metric: "Profit", unit: "%", actual: 22.5, target: 26, ranges: [20, 25, 30] },
];

<BulletChart
  data={data}
  config={chartConfig}
  labelDataKey="metric"
  descriptionDataKey="unit"
  valueDataKey="actual"
  targetDataKey="target"
  rangesDataKey="ranges"
  rangeLabels={["Poor", "Satisfactory", "Good"]}
>
  <BulletChart.Tooltip />
  <BulletChart.Axis />
  <BulletChart.Ranges />
  <BulletChart.Measure />
  <BulletChart.Target />
</BulletChart>
```

Range thresholds are ascending upper bounds: `[150, 225, 300]` draws bands from 0 to 150, 150 to 225, and 225 to 300. Give the chart roughly 56px per row with an axis, or 36px without one.

## API Reference

<ApiHeading>BulletChart</ApiHeading>

<ApiTable>
  <ApiRow name="data" type="TData[]" required>
    One row per bullet.
  </ApiRow>
  <ApiRow name="config" type="ChartConfig" required>
    Labels and colors for the measure and target keys. Without a target color, the tick uses the foreground color.
  </ApiRow>
  <ApiRow name="labelDataKey" type="keyof TData & string" required>
    The row title.
  </ApiRow>
  <ApiRow name="valueDataKey" type="keyof TData & string" required>
    The measure drawn as the bar.
  </ApiRow>
  <ApiRow name="descriptionDataKey" type="keyof TData & string">
    A second line under the title, such as a unit.
  </ApiRow>
  <ApiRow name="targetDataKey" type="keyof TData & string">
    The comparative measure drawn as the tick.
  </ApiRow>
  <ApiRow name="rangesDataKey" type="keyof TData & string">
    A field holding ascending range thresholds.
  </ApiRow>
  <ApiRow name="maxDataKey" type="keyof TData & string">
    A field that sets each row's scale maximum.
  </ApiRow>
  <ApiRow name="rangeLabels" type="string[]">
    Names for the ranges, from the first threshold up, shown in the tooltip.
  </ApiRow>
  <ApiRow name="labelWidth" type="number" default="128">
    Width of the label column in pixels.
  </ApiRow>
  <ApiRow name="animation" type="boolean" default="true">
    Grows each measure in, row by row. Reduced-motion preferences turn it off.
  </ApiRow>
  <ApiRow name="isLoading" type="boolean" default="false">
    Shows placeholder rows and the loading label.
  </ApiRow>
  <ApiRow name="ariaLabel" type="string">
    Accessible name for the canvas. Every row's value and target are read when omitted.
  </ApiRow>
  <ApiRow name="chartOptions" type="Record<string, unknown>">
    Escape hatch merged over the generated ECharts option.
  </ApiRow>
</ApiTable>

<ApiTable>
