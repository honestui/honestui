## Overview

Circular Text sets a short phrase around a circle and turns it slowly. The spacing stretches so the text closes into an even ring with no gap, and anything you pass as children sits in the middle, such as an arrow, a logo, or a version number.

Use it for one expressive badge on a marketing page: "Now hiring", "Scroll to explore", or a release stamp. Keep the phrase short. The text is hard to read while it turns, so never put information people need only in the ring.

## Usage

```tsx
import { CircularText } from "@/components/animated/circular-text"

<a href="/careers">
  <CircularText text="Now hiring" repeat={3}>
    <ArrowUpRight className="size-5" />
  </CircularText>
</a>
```

`repeat` sets how many times the phrase goes around, and `separator` is placed after each repeat. Use `textClassName` for weight, case, or color, and `className` on the root for the text color through `currentColor`.

Hovering speeds the ring up by default. Set `onHover` to `"slowDown"`, `"pause"`, or `"none"` to change that.

## Accessibility

Screen readers hear the phrase once, from visually hidden text; the rotating SVG is hidden from them. Inside a link or button, that text becomes its accessible name, so the phrase should describe where the link goes.

The ring only turns while it is on screen. With reduced motion it stays still, and `paused` stops it for everyone.
