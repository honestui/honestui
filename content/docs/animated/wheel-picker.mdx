## Overview

Wheel Picker is suited to short ordered choices such as times, durations, or compact numeric ranges. Drag, wheel, click, and keyboard input all settle on the same row detents.

## Installation

<CliBlock commands={["wheel-picker"]} />

## Usage

```tsx
import { WheelPicker } from "@/components/animated/wheel-picker"

<WheelPicker options={["13:30", "14:00", "14:30"]} defaultValue="14:00" aria-label="Focus session" />
```

## Accessibility

Provide an accessible label and keep option labels concise. Keyboard users can move by row, jump to the ends, and select without drag. Sound is off by default and should remain optional.

## API Reference

<ApiTable>
  <ApiRow name="options" type="WheelPickerOption[]" required>Strings or `{ value, label }` options.</ApiRow>
  <ApiRow name="value" type="string">Controlled selected value.</ApiRow>
  <ApiRow name="defaultValue" type="string">Initial uncontrolled value.</ApiRow>

  <ApiRow name="sound" type="boolean" default="false">Plays a short tick when the selected row changes.</ApiRow>
