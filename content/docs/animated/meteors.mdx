## Overview

Meteors draws thin streaks that fall diagonally across their parent at staggered times and speeds. Use it sparingly behind a hero, a changelog entry, or a launch card. Positions come from a seeded generator, so the server and client render the same layout and there is no hydration mismatch; change `seed` for a different arrangement.

## Usage

```tsx
import { Meteors } from "@/components/animated/meteors"

<div className="relative overflow-hidden rounded-xl border p-6">
  <Meteors number={16} />
  <h3 className="relative">Faster cold starts</h3>
</div>
```

Meteors fills and clips to its nearest positioned ancestor. Give foreground content `relative` so it stacks above the streaks.

## Accessibility

The streaks are decorative and hidden from assistive technology. Keep text contrast high where streaks cross it. When reduced motion is requested, the streaks are not shown at all.
