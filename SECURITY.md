# Security Policy

## Supported versions

Security updates are applied to the latest released version of Honest UI. We
recommend upgrading to the newest release before reporting an issue that may
already have been fixed.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions,
or pull requests.

Use GitHub's private vulnerability reporting to
[report a vulnerability](https://github.com/honestui/honestui/security/advisories/new).
Include a clear description, reproduction steps or proof of concept, affected
versions, and the impact you believe the vulnerability has.

The maintainers will acknowledge the report as soon as practical, keep you
informed while it is investigated, and coordinate disclosure when a fix is
available. Please allow time for a patch before sharing the issue publicly.
